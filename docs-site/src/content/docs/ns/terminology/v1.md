## Versioning policy

The `v1` segment versions the serialized XML contract, not the npm package.
Ordinary package releases and backward-compatible additions keep this URI unchanged.
An incompatible removal, rename or semantic change requires maintainer approval,
a new namespace version and a documented migration path. Package releases remain
in the `0.x` series until the project deliberately declares a stable public release.

The extension family follows the pattern
`https://forschungsgruppe-digital-health.github.io/<repository>/ns/<extension>/v<format-major>`.
