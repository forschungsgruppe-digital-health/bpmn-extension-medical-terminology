              bevorzugte Sprachen) und die Adresse dieser Demo. Damit möglichst wenige Anfragen entstehen,

              Lizenzierte Nutzerinnen und Nutzer können es danach mit einer gesonderten Selbstauskunft zur
              Lizenz freischalten.
            
            
              For every search in LOINC®, ICD-10-GM, OPS, or ATC (and
              SNOMED CT®, if you unlock it), your browser sends a request directly to
              . It contains the search term and the code system and, as
              with any web request, your IP address, the time, browser details (user agent, preferred
              languages) and the address of this demo. To keep the number of requests low, a search is sent
              only from three characters on and after you pause typing.
