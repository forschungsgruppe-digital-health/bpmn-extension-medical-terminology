#### SNOMED CT and LOINC identifiers in HL7 concepts

HL7's own code systems use a few SNOMED CT and LOINC identifiers, and the bundle keeps them:

- **SNOMED CT:** 13 code systems use the SNOMED CT concept `900000000000013009` (Synonym)
  308 times as `designation.use`, to mark a designation as a synonym. The code systems, all
  under `http://terminology.hl7.org/CodeSystem/`, are `state-change-reason`, `v3-ActClass`,
  `v3-ActCode`, `v3-ActRelationshipType`, `v3-AmericanIndianAlaskaNativeLanguages`,
  `v3-DataType`, `v3-EntityClass`, `v3-HL7ConformanceInclusion`, `v3-RoleClass`,
  `v3-RoleCode`, `v3-RouteOfAdministration`, `v3-SpecimenType` and `v3-mediaType`.
- **LOINC:** `http://terminology.hl7.org/CodeSystem/v3-ActCode` contains five LOINC codes as
  concepts under `_LOINCObservationActContextAgeType`, with the display names given in HL7's
  code system: `21611-9`, `21612-7`, `29553-5`, `30525-0` and `30972-4`.

Some HL7 definitions also mention individual SNOMED CT or LOINC codes as examples.

- `http://terminology.hl7.org/CodeSystem/ADAUniversalToothDesignationSystem` (American Dental

- `http://terminology.hl7.org/CodeSystem/ADAToothSurfaceCodes` (American Dental Association)
- `http://terminology.hl7.org/CodeSystem/v3-HealthcareProviderTaxonomyHIPAA` (NUCC Health
  Care Provider Taxonomy; retired)
- `http://terminology.hl7.org/CodeSystem/color-names` (CSS colours, World Wide Web Consortium)
- `http://terminology.hl7.org/CodeSystem/color-rgb` (CSS colours, World Wide Web Consortium)

If you need them, license them from their owner and serve them from your own terminology
server. The installed `hl7.terminology.r4` dependency still contains these files. Default
package discovery (the Vite plugin, the `fdh-terminology-discover` CLI and
`packageAutoDiscovery`) leaves them out like the bundled preset, but packages you select
explicitly are not filtered; importing them that way needs their owners' licences.

## Terminologies that are not included

The package contains **no SNOMED CT, LOINC, ICD-10-GM, OPS or ATC code system**: no display
names, descriptions or hierarchies from them. The only exceptions are the SNOMED CT and LOINC
identifiers, and the display names HL7 gives the five LOINC codes, listed above. The package
does not preconfigure a terminology server for these terminologies. They are available only
after you set `serverConfig.fhirBaseUrl` to a server you are licensed to use. For SNOMED CT
you must also set `snomedConfig.edition` to the edition covered by your licence.

### Public terminology servers

A terminology server you connect has its own terms of use, in addition to the publishers'
